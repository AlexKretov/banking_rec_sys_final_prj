# FastAPI-сервис T-ECD

После выполнения `python tecd_pipeline.py data/t_ecd` каталог `artifacts/` содержит:

- `model.joblib` — ALS, модель второго уровня и отображения идентификаторов;
- `metadata.json` — параметры временного разбиения, размер выборки и фактически рассчитанные метрики.

Запуск из этого каталога:

```bash
uvicorn app2:app --host 0.0.0.0 --port 8079
```

`POST /predict` принимает `user_id`, `top_k` и необязательный контекст (`domain`, `subdomain`, `os`). Идентификатор должен встречаться в обучающем периоде T-ECD. Путь к модели можно переопределить переменной `MODEL_PATH`.
