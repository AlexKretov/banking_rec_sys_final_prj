# Миркосервис на FastAPI

Пока что здесь только app2.py, но в ходе отработки файла modeling.py здесь сформируются ещё файлы:  
- personal_als.parquet - файл с персональными рекомендациями, которые используются как дополнительный признак при рекомендациях;  
- replacer.json - файл со словарём для замены редко встречающихся значний;
- saved_model.pkl - непосредственно модель, уже обученная делать предсказания.
